# Tcc-Cibersecurity

Trabajo Colaborativo Contextualizado (TCC) de **Seguridad Informática** —
Universidad de Cartagena, Programas a Distancia.

**Tema:** Seguridad Web (OWASP Top 10) + Criptografía aplicada.
Auditoría de una aplicación web vulnerable (DVWA) en un **laboratorio aislado**,
demostrando XSS, Inyección SQL y Fuerza Bruta, y aplicando sus contramedidas
(incluido el hash de contraseñas con sal).

> ⚠️ Todas las pruebas se realizan en un laboratorio aislado contra un objetivo
> deliberadamente vulnerable. Nunca contra sistemas reales.

## Contenido

El proyecto completo está en [`proyecto-tcc/`](proyecto-tcc/):

- `documento/` — documento del TCC según la plantilla oficial.
- `diseno/` — arquitectura segura, flujo de datos + STRIDE, tabla de controles.
- `laboratorio/` — guías de montaje (Docker y VirtualBox) y playbook de ataques.
- `scripts/` — demostración de criptografía (hash con sal).
- `evidencias/` — capturas, logs y pruebas antes/después de cada ataque.
- `sustentacion/` — diapositivas y guion de la exposición.

Ver el detalle en [`proyecto-tcc/README.md`](proyecto-tcc/README.md).
